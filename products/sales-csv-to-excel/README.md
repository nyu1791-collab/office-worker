# 商品: 複数店舗の売上CSV → 集計Excel

店舗・ECモール・POS ごとにバラバラに出てくる売上CSVを、フォルダに入れてダブルクリックするだけで
**明細・店舗別・日別・日別×店舗・要確認** の5シートの Excel にまとめるツール。

| 項目 | 内容 |
|---|---|
| 対象 | 2店舗以上の売上CSV/Excelを毎月（毎日）手で貼り合わせている小売・飲食・美容・EC |
| 納品物 | `売上集計.exe` ＋ `recipe.yaml`（列名設定）＋ 説明書（MANUAL.md） |
| 価格の目安 | 基本 3万円（列名の対応・検収まで）／ 列や集計の追加 1項目 5千円〜／ 保守 月3千円〜 ※要調整 |
| 納期の目安 | サンプルCSV受領から 3営業日 |
| 動作環境 | Windows 10/11（Python 不要） |

## できること（同梱サンプルで実証済み）
- 文字コード混在（UTF-8 / Shift_JIS）、店ごとに違う列名（`日付`/`売上日`、`金額`/`金額（税込）`）
- `1,500` `９００` `1000円` `▲300`（返品）を数値化、`2026年10月1日` `令和8年10月2日` `20261003` を日付化
- 同じ日・店・商品の **2件目も正しく売上として数える**（行を勝手に重複削除しない）
- 同じCSVを2回入れても **1回分だけ** 数える（中身が同一のファイルを除外）
- 日付・店舗・金額が空/読めない行は集計に入れず **要確認シート** へ（黙って消さない）
- 売上CSVではないファイルは処理せず、理由を表示して `in` に残す

## 範囲外（別見積）
- POS/モールからの自動ダウンロード、Googleスプレッドシート連携、メール送信
- 税抜/税込の換算、手数料差引、商品マスタとの突合、前年比などの分析シート
- 画像PDFの読み取り

## ファイル
| ファイル | 用途 |
|---|---|
| `SPEC.md` | 入力仕様と、受注時に顧客と決める項目（ヒアリングシート） |
| `ACCEPTANCE.md` | 検収条件（何をもって完成とするか） |
| `MANUAL.md` | お客様向け説明書（そのまま納品） |
| `DELIVERY.md` | 納品手順（自分用） |
| `recipe.yaml` | 処理内容。顧客ごとの列名はここの `rename` に追加 |
| `run.py` / `build.ps1` | 実行入口 / exe 作成 |
| `sample/` | デモ用入力と期待結果（`expected.json`）。`tests/test_product_sales.py` が自動照合 |

## デモ（営業・商談で見せる）
```powershell
.\.venv\Scripts\python products\sales-csv-to-excel\run.py --sample
# → products\sales-csv-to-excel\sample\out\売上集計_YYYYMMDD.xlsx
```
