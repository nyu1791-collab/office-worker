# 売上集計ツール 説明書

## 使い方（毎回これだけ）
1. `売上集計.exe` と同じ場所の **`in` フォルダ** に、各店舗の売上CSV（またはExcel）を入れる
2. `売上集計.exe` をダブルクリック
3. 黒い画面に「==== 結果 ====」が出たら Enter で閉じる
4. **`out` フォルダ** の `売上集計_日付.xlsx` を開く

## Excel の見方
| シート | 内容 |
|---|---|
| 明細 | 全店舗の売上を1つに並べたもの（どのファイルから来たかも表示） |
| 店舗別 | 店舗ごとの売上合計と件数（多い順） |
| 日別 | 日ごとの売上合計と件数 |
| 日別×店舗 | 縦が日付・横が店舗の表。右端と最下行が合計 |
| 要確認 | 日付・店舗・金額が空欄や読めない行。**集計に入っていません**。元のCSVを直して再実行してください |

## 画面にこう出たら
| 表示 | 意味と対処 |
|---|---|
| 二重投入として除外: ○○ (1).csv | 同じ中身のファイルが2つあったので1つだけ数えました。対処不要 |
| 読めなかったファイル: ○○.csv … 必須の列（日付・店舗・金額）が見つかりません | 売上CSVではないか、見出しの名前が違います。売上CSVなら見出し名をご連絡ください（設定で対応します） |
| エラー: … | 画面を撮影してご連絡ください |

## よくある質問
- **返品はどうなる？** `▲300` `-300` のようなマイナスの金額は合計から差し引きます
- **同じ商品が同じ日に2回売れたら？** 2件とも売上として数えます
- **前月のファイルも入っていたら？** `in` にある全ファイルを集計します。月ごとに分けたい場合は、集計したい月のファイルだけを `in` に入れてください
- **「WindowsによってPCが保護されました」と出た** 「詳細情報」→「実行」を押してください
