# 入力仕様とヒアリング項目

## 標準の入力
- 置き場所: `in` フォルダ（サブフォルダは見ない）
- 形式: `.csv`（UTF-8 / UTF-8 BOM / Shift_JIS）、`.xlsx`（先頭シート）
- 1行目が見出し。必須列は **日付・店舗・金額**、任意で **商品**
- 標準で認識する見出し（全角/半角・空白の違いは無視）

| 意味 | 認識する見出し |
|---|---|
| 日付 | 日付 / 売上日 / 営業日 / 取引日 |
| 店舗 | 店舗 / 店舗名 / 店名 |
| 商品 | 商品 / 商品名 / 品名 |
| 金額 | 金額 / 金額(税込) / 税込金額 / 売上金額 / 売上 |

これ以外の見出しは `recipe.yaml` の `rename` に1行足して対応する（例: `売上高: amount`）。

## 値の扱い
| 入力例 | 扱い |
|---|---|
| `1,500` `９００` `1000円` | 1500 / 900 / 1000 |
| `▲300` `△300` `(300)` `-300` | -300（返品・値引として合計から引く） |
| `2026/10/1` `2026-10-01` `2026年10月1日` `令和8年10月1日` `R8.10.1` `20261001` | 2026-10-01 |
| 空欄・読めない日付/金額、店舗が空 | 集計に入れず「要確認」シートへ |
| 同じ日・店・商品・金額の行が複数 | **すべて売上として数える** |
| 中身が完全に同じファイルが2つ | 1つだけ数える（`売上 (1).csv` のような二重投入対策） |
| 必須列が無いファイル | 処理せず `in` に残し、画面と `error.log` に理由 |

## 受注時に顧客と決める項目（ここを spec に書いて検収条件にする）
1. 実データのサンプル（各店1ファイル・個人情報は伏せてもらう）と、手作業で作った正解の集計（1か月分）
2. 見出しが標準と違う列の対応
3. 金額は税込か税抜か（ツールは換算しない。入力の値をそのまま合計）
4. 伝票番号の有無。**同じCSVを期間を重ねて出力し直す運用**がある場合は、伝票番号で重複を除く設定を追加（`dedupe: [伝票番号]`）
5. 締め日・集計期間（標準は `in` に入っている全期間）
6. 出力ファイル名・保存先（標準 `out/売上集計_実行日.xlsx`、同日の再実行は上書き）
