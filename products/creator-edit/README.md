# 商品: クリエイター向け モザイク＆集客ショート代行

長尺動画を預かり、**自動モザイク（追従）**と **X 用の縦型サンプル**を作って納品。人は「要確認区間」だけ目視・補正する。

| 項目 | 内容 |
|---|---|
| 料金の目安 | 1本 3,000〜5,000円 ／ 月 5〜10万円（15〜20本）※要調整 |
| 初回 | 1本無料（モザイク＋ショート3本） |
| 処理時間の目安 | 1080p・30分の動画で検出 15〜40分（`--step 2` で約半分）＋ 目視は要確認区間のみ |

## 受付（必須）
`jobs/<案件>/intake.yaml` の3項目が true でないと処理しない（初回実行で雛形ができる）
- 出演者全員が **身分証で18歳以上**であることを確認
- 出演者全員の撮影・公開の**同意の記録**
- 依頼者が**権利者**（または許諾あり）

## 手順
```powershell
.\setup.ps1 -WithMedia
python -m officeworker new 顧客名_0001          # jobs/顧客名_0001/in に元動画
python -m officeworker creator-job jobs\顧客名_0001 -n 3 --len 20
```
出力: `out/mosaic/*_mosaic.mp4`、`out/review/<動画>/要確認区間.csv` と静止画、`out/clips/*.mp4`（1080×1920）

1. `要確認区間.csv` の時刻だけ倍速で確認 → 抜けていれば CapCut / DaVinci で該当フレームを補正
2. ショートは **モザイク済み動画から**切り出す（creator-job は自動でそうなる）。X ではアカウントの「センシティブな内容」設定を必ず使ってもらう
3. 納品後、元動画・作業ファイルは契約どおり削除

## 精度を上げる（任意）
- 既定は NudeNet（MIT）の学習済みモデル。対象が合わなければ自作 YOLO を `--detector yolo:model.pt`
- `--classes jp+breast`（媒体の規約に合わせる）、`--style blur|black|stamp --stamp hide.png`
- 検出漏れの補間時間 `--max-gap 1.5`、モザイクの粗さ `--block 24`
